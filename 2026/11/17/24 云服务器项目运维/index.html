5.10 iccctl脚本-设备情况

iccctl 目前有 8 个命令，其中 6 个只读，2 个会实际改动设备：

命令 作用 是否改动现场
status 运行概览：服务在不在跑、MQTT 连没连、各类设备在线数 无
devices 全部设备状态明细（ID、类型、状态、在线、更新时间、错误） 无
siren [设备ID] 声光状态 + 音量 + 曲目，不传 ID 列 7 台 无
siren [设备ID] --live 同上，但逐台读设备寄存器拿真实音量 无（会临时占串口）
volume <设备ID> <0-30> 设置单台声光音量 有
cmds [N] 最近 N 条指令，默认 20 条 无
logs [N] 最近 N 行业务日志，默认 30 行 无
send <设备ID> <on|off|stop> 下发一条指令并等 ACK，走的是平台同一条 MQTT 链路 有
watch 实时跟踪 ACK，Ctrl+C 退出 无

常用几条

几个约定

  • 设备 ID 一律用 sensorName（ankang-siren-01、ankang-relay-06、ankang-gate-01），./iccctl devices 能看到全部。
  • send 的 switch 严格区分大小写，只认 on / off / stop；stop 只有道闸支持，其他设备会明确拒绝，不会降级成 off。
  • 道闸方向与直觉相反：on = 伸出封路，off = 收回放行。
  • 参数不够或命令写错返回码 2，并打印用法。

另外，刚才改的「起播时设音量」不新增命令，但 ./iccctl cmds 里起播的 detail 会变成 start track=1 volume=30，能直接看出音量有没有一起下发。
